Snake Squad

A cooperative snake game. Add it to your home screen and it opens like any other app.

You're all set

Snake Squad is installed on this device.

Open the game

iPhone & iPad

  1. Open this page in Safari (other browsers can't install it properly).
  2. Tap the Share button — the square with an arrow pointing up.
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add, then launch Snake Squad from your home screen.

Android

  1. Open this page in Chrome.
  2. Tap the ⋮ menu, top right.
  3. Tap Add to Home screen (or Install app), then confirm.

Launching it from the home screen matters — that's what makes it run fullscreen without browser toolbars. You can also play in the browser, but the game is designed for the installed version.
